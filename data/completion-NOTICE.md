# Korean completion dictionary notice

`completion.txt` combines two sources in display-priority order.

`nextword.txt` is a separate, small project-curated previous-eojeol mapping for
offline next-word suggestions. It was not generated from either completion
source below and contains no user input or learned usage data.

1. Short mobile conversation forms authored for this project.
2. Complete-Hangul headwords derived from the National Institute of Korean
   Language's **Korean learning vocabulary list** (`한국어 학습용 어휘 목록`).

The source dataset contains 5,965 entries with a frequency rank and proficiency
level. It is provided under the Korea Open Government License Type 1 (KOGL Type
1), which permits commercial and non-commercial use and modification with
attribution.

- Provider: National Institute of Korean Language (국립국어원)
- Source page: https://www.korean.go.kr/front/etcData/etcDataView.do?etc_seq=70&mn_id=46&pageIndex=44
- Download SHA-256: `3B49681F05D6A7490C13DA2A2847E433EFFDF65DA409FD295792D6EE33685064`
- Generated by: `scripts/generate-korean-completion-dictionary.ps1`
- Changes: CP949 decoding, trailing two-digit dictionary sense marker removal,
  complete-Hangul word filtering, duplicate removal, and project-authored mobile
  conversation forms placed before source-frequency-ranked entries.
